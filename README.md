# Kansai SC

Website project connected to:
https://github.com/contactjapanvn/kansaisc.git

## Setup

```bash
# After Xcode Command Line Tools install finishes:
cd ~/Desktop/kansaisc
git init
git remote add origin https://github.com/contactjapanvn/kansaisc.git
git add .
git commit -m "Initial website scaffold"
git branch -M main
git push -u origin main
```

## Run locally

Open `index.html` in the browser, or:

```bash
npx serve .
```
